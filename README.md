# 宝可梦世界(AstrBot 插件)

> 强规则的宝可梦文字冒险:地图探索 · 道馆挑战 · 捕获培养 · 每天凌晨 4 点世界刷新。
> 所有数值由内置的确定性内核结算,LLM 只负责叙事与每日事件的选题文案。

**与《转生模拟器》的关系**:本项目复用了 `astrbot_plugin_life_sim` 的宝可梦数据与对战
引擎(图鉴 / 特性 / 学习表 / 属性相克 / 620 处真实地点野外分布 / 1379 张缩略图),
但玩法层完全重写 —— 从「靠 LLM 叙述的跑团」变成「有明确规则、可长期游玩的游戏」。

---

## 一句话玩法

```
/开始 小智 新叶喵   →   /探索   →   /对战 1   →   /捕捉 精灵球
   →   /前往 常青市   →   /道馆 挑战   →   /联盟 挑战   →   下一个地区
```

## 特性

### 🗺️ 真实地图(8 个地区 / 609 个地点)
- 关都、城都、丰缘、神奥、合众、卡洛斯、阿罗拉、伽勒尔,按**真实游戏顺序**串联成图。
- 相邻才可步行前往;同一地区集齐 3 枚徽章解锁**飞行**(可回到去过的城镇,500₽)。
- 每个地点按**危险度(tier)**设徽章门槛,避免新手冲进冠军之路。
- 每个地区的野外分布来自真实版本数据(默认取该地点最新版本组),
  41 种遭遇方式(草丛 / 冲浪 / 钓竿 / 摇晃 / 大量出现…)。
- 通关上一地区冠军后自动开放下一地区。

### ⚔️ 确定性对战引擎
- Gen9 机制的伤害/命中/会心/属性相克/异常状态/能力变化/天气场地/入场陷阱/太晶化。
- 支持:出招、换人、使用道具、投球捕获、逃跑、认输、太晶化。
- 野生 / 道路训练家 / 道馆馆主 / 四天王 / 冠军 / 火箭队,全部走同一套引擎。

### 🏛️ 真实道馆数据(67 个道馆 + 32 位四天王 + 8 位冠军)
- 馆主、徽章、属性、队伍与等级取自真实游戏版本:
  关都 FRLG · 城都 HGSS · 丰缘 ORAS · 神奥 Platinum · 合众 B2W2 · 卡洛斯 XY · 伽勒尔 SwSh · 阿罗拉 USUM。
- 例:小刚(岩石)小拳石 Lv12 / 大岩蛇 Lv14;青绿冠军 比雕 Lv59 起。
- 阿罗拉以「考验 + 大考验 + 岛屿之王」替代道馆。

### 🐾 培养
- 经验/升级按图鉴成长曲线;升级学招(招式满 4 个时进入「待学」队列,`/学招` 决定替换)。
- 进化覆盖:等级 / 亲密度 / 携带道具 / 学会指定招式 / 能力值分支 / 性别 / 昼夜 / 使用道具 / 通信交换。
- 捕获率、精灵球加成、异常状态加成、摇晃次数与真实公式一致。
- 性格 / 个体值 / 努力值 / 特性 / 太晶属性 / 性别 / 亲密度。
- 图鉴双记录(见到 / 捕获),`/图鉴` 可反查野外分布地点与等级区间。

### 🌍 每天凌晨 4 点刷新世界
- **世界事件**(全群共享):火箭队占据某地并封锁道路、宝可梦大量出现、稀有宝可梦现身、
  天气异常、商店清仓、庆典、道路封锁、旅人传闻。
- **个人事件**(每人独立):捡到道具/零花钱、遭遇野生宝可梦、训练家挑战、与宝可梦增进感情、私人线索。
- 由 LLM 按**严格 JSON** 生成:事件种类、地点、数值修正全部限定在枚举与区间内,
  越界的数值会被裁剪(例如 `encounter_mult: 999 → 3.0`)。
- LLM 不可用/超时/输出非法 → 自动回退本地确定性事件生成器,**游戏永不空转**。
- 机器人离线也不会漏:任意指令都会触发「懒刷新」补齐当天事件。

### 🧩 强规则(为什么不会被 LLM 玩坏)
| 层 | 职责 |
|---|---|
| `pw/dex.py` `pw/engine.py` `pw/growth.py` | 全部数值判定(不可被自然语言覆盖) |
| `pw/world.py` `pw/worldstate.py` `pw/daily.py` | 地图通行、事件施加与裁剪、日界 |
| `pw/narrate.py` + `prompts.py` | 只把**既成事实**润色成叙事,提示词明确禁止改动数值 |
| `main.py` | 指令 = 唯一的状态入口 |

## 安装

1. 把本目录放进 AstrBot 的 `data/plugins/astrbot_plugin_pokemon_world/`。
2. 无需 pip 安装任何依赖(数据已内置,运行时不联网)。
3. 在 WebUI 插件配置里填 `provider_id`(用于每日事件与叙事润色;留空则关闭 LLM 功能)。

## 指令一览

| 指令 | 说明 |
|---|---|
| `/开始 [名字] [宝可梦]` | 创建训练家(默认参考《朱/紫》御三家:新叶喵 / 呆火鳄 / 润水鸭) |
| `/状态` `/队伍` `/背包` | 档案 / 队伍 / 背包 |
| `/地图 [地区]` | 当前地区与相邻地点、危险度、道馆位置 |
| `/前往 <地点>` · `/前往 飞行 <城镇>` | 移动 |
| `/探索` | 探索当前地点(野生 / 道具 / 训练家 / 事件) |
| `/对战 <行动>` | `move <招式>`、招式序号、`tera move <招式>`、`switch <序号>`、`item <道具>`、`run`、`forfeit` |
| `/捕捉 <精灵球>` | 投球捕获(仅野生) |
| `/训练家战 [序号]` | 挑战本地点训练家 |
| `/道馆` · `/道馆 挑战` | 道馆信息 / 开战 |
| `/联盟 [挑战]` | 四天王与冠军(需 8 枚徽章 + 在联盟地点) |
| `/学招 <序号> <招式> [替换 <序号\|招式>]` | 学习/替换招式 |
| `/进化 <序号> [道具]` | 查看或执行进化 |
| `/图鉴 <名字>` | 图鉴资料 + 野外分布 |
| `/商店` · `/商店 买 <道具> [数量]` · `/商店 卖 <道具> [数量]` | 商店 |
| `/治疗` | 在宝可梦中心恢复 |
| `/今日` | 今日世界事件与个人事件 |
| `/重置世界 [all]` | 删除存档(管理员可清全群) |
| `/帮助` | 全部指令 |

## 配置项

| 键 | 默认 | 说明 |
|---|---|---|
| `provider_id` | 空 | LLM 提供商;留空 = 关闭 LLM(游戏仍完整可玩) |
| `narrate_enable` | 开 | LLM 叙事润色 |
| `event_enable` | 开 | 每日 4 点事件生成 |
| `event_hour` | 4 | 刷新时刻 |
| `announce_events` | 开 | 到点在会话里广播「第 N 天开始了」 |
| `narrate_every_turn` | 关 | 每个战斗回合都叙事(更贵) |
| `sprite_enable` | 开 | 队伍附带宝可梦缩略图 |
| `starter_choices` | 空 | 自定义可选御三家(逗号分隔) |
| `admin_uids` | 空 | 管理员 QQ,可 `all` 清档 |

## 数据来源与规模

| 内容 | 数量 | 来源 |
|---|---|---|
| 宝可梦形态 | 1380 | PokeAPI CSV(经 `poke-env` wheel)+ 52poke 中文名/说明 |
| 招式 | 950(824 有中文说明) | 同上 |
| 特性 | 316(265 有中文说明) | 同上 |
| 学习表 | 1231 | 同上 |
| 地点 / 野外分布 | 609 地点、41 种遭遇方式 | 同上 |
| 地图图 / 道馆 | 8 地区 / 609 节点 / 67 道馆 | `tools/build_map_graph.py`、`tools/build_gym_data.py` |
| 缩略图 | 1379 张 96×96 | PokeAPI sprites |

> **已知缺口**:上游 `locations.json` 完全没有**帕底亚**的野外数据,因此《朱/紫》地区
> 无法生成地图与野外遭遇;但《朱/紫》的御三家与宝可梦(Gen9 全量)都能正常获得与对战。

## 开发

```bash
# 重建地图图(基于 locations.json)
python tools/build_map_graph.py      # → pw/static/maps.json
# 重建道馆数据(真实游戏数据,内置于脚本)
python tools/build_gym_data.py       # → pw/static/gyms.json
# 测试
python -m pytest tests/ -q           # 27 passed
ruff check .
```

两个构建脚本都带自检(相邻关系对称、单连通、tier 范围、道馆地点/物种/等级校验),
失败会以非 0 退出码结束。
