# 宝可梦世界(AstrBot 插件)

> 强规则的宝可梦文字冒险:地图探索 · 道馆挑战 · 捕获培养 · 每天凌晨 4 点世界刷新。
> 所有数值由内置的确定性内核结算,LLM 只负责叙事与每日事件的选题文案。

**与《转生模拟器》的关系**:本项目复用了 `astrbot_plugin_life_sim` 的宝可梦数据与对战
引擎(图鉴 / 特性 / 学习表 / 属性相克 / 620 处真实地点野外分布 / 1379 张缩略图),
但玩法层完全重写 —— 从「靠 LLM 叙述的跑团」变成「有明确规则、可长期游玩的游戏」。

---

## 一句话玩法

```
/开始 小智 新叶喵   →   /探索   →   /对战 1   →   /捕捉 精灵球
   →   /前往 常青市   →   /道馆 挑战   →   /联盟 挑战   →   下一个地区
```

## 特性

### 🗺️ 真实地图(8 个地区 / 596 个地点)
- 关都、城都、丰缘、神奥、合众、卡洛斯、阿罗拉、伽勒尔,按**真实游戏顺序**串联成图。
- 相邻才可步行前往;同一地区集齐 3 枚徽章解锁**飞行**(可回到去过的城镇,500₽)。
- 每个地点按**危险度(tier)**设徽章门槛,避免新手冲进冠军之路。
- 每个地区的野外分布来自真实版本数据(默认取该地点最新版本组),
  41 种遭遇方式(草丛 / 冲浪 / 钓竿 / 摇晃 / 大量出现…)。
- 通关上一地区冠军后自动开放下一地区。

### ⚔️ 确定性对战引擎
- Gen9 机制的伤害/命中/会心/属性相克/异常状态/能力变化/天气场地/入场陷阱/太晶化。
- 支持:出招、换人、使用道具、投球捕获、逃跑、认输、太晶化。
- 野生 / 道路训练家 / 道馆馆主 / 四天王 / 冠军 / 火箭队,全部走同一套引擎。

### 🏛️ 真实道馆数据(67 个道馆 + 32 位四天王 + 8 位冠军)
- 馆主、徽章、属性、队伍与等级取自真实游戏版本:
  关都 FRLG · 城都 HGSS · 丰缘 ORAS · 神奥 Platinum · 合众 B2W2 · 卡洛斯 XY · 伽勒尔 SwSh · 阿罗拉 USUM。
- 例:小刚(岩石)小拳石 Lv12 / 大岩蛇 Lv14;青绿冠军 比雕 Lv59 起。
- 阿罗拉以「考验 + 大考验 + 岛屿之王」替代道馆。

### 📜 主线剧情(和正作一样)
- 每个地区 6 个章节:**出发 → 首枚徽章 → 击退敌对组织(2 次) → 联盟 → 冠军后的收尾**。
- 敌对组织与首领按原作设定,并放在原作的地点:
  | 地区 | 敌对组织 | 首领 | 剧情战斗地点 |
  |---|---|---|---|
  | 关都 | 火箭队 | 坂木 | 月见山 → 西尔佛公司(5 徽章) |
  | 城都 | 火箭队残党 | 坂木 | 呆呆兽之井 → 满金市电台(7 徽章) |
  | 丰缘 | 水舰队与火岩队 | 水梧桐/赤焰松 | 石之洞窟 → 海底洞窟(6 徽章) |
  | 神奥 | 银河队 | 赤日 | 百代市 → 天冠山(6 徽章) |
  | 合众 | 等离子队 | N/魁奇思 | 矢车森林 → 古代之城(6 徽章) |
  | 卡洛斯 | 闪焰队 | 弗拉达利 | 闪耀洞窟 → 闪焰队秘密基地(7 徽章) |
  | 阿罗拉 | 骷髅队 | 古兹马 | 海滩洞穴 → 以太乐园(6 徽章) |
  | 伽勒尔 | 呐喊队 | 马俐/聂凯 | 草路镇 → 拳关市(7 徽章) |
- 徽章不够时章节不会跳过,面板会直接告诉你"还差几枚徽章"。

### 🐉 神兽(**40 个定点**,特定地点 + 进度阶段)
- 条件 = **在正确的地点** + **足够徽章** (部分需要先成为冠军),和正作一致。
- 例:急冻鸟@双子岛(4 徽章)、超梦@华蓝洞窟(冠军后)、烈空坐@天空之柱(冠军后)、
  卡璞・鸣鸣@战争遗迹(6 徽章)、无极汰那@能源工厂(8 徽章)。
- **捕获率极低**(传说的宝可梦多为 3/255),普通球几乎抓不到 —— 攒大师球吧。
- 战斗失败/把它打倒 → 它当天逃走,**次日可再来**;成功捕获则永久入队。
- `/神兽` 会按你的进度给出"已知栖息地"与"传闻中还有别的存在"。

### 🏆 世界大赛(冠军后解锁)
- 成为任意地区冠军后开放。三轮淘汰赛:**八强 → 四强 → 决赛**。
- 对手从**其它地区的冠军与四天王**里抽(取自真实游戏数据),等级 70→88 递增。
- 首度夺冠奖励:大师球 ×1、神奇糖果 ×3、20000₽ 与「世界冠军」称号。

### 📋 支线委托(每天刷新,必须真的做事才能完成)
- 每天凌晨 4 点随世界刷新 **2 条**委托(上限同时 4 条,3 天未完成自动失效)。
- **强规则**:目标只挂在真实行为上 —— 捕获 N 只(可按属性/钓法限定)、击败 N 只野生、
  战胜 N 位训练家、道馆挑战、**不使用道具取胜**、进化、升级、登记新图鉴、
  前往新地点、在商店消费 N₽、走路 N 步……**没有任何"过一天自动完成"的目标**。
- 委托主题(委托人 / 标题 / 说明)可由 LLM 每天生成,但**数值全部由内核裁剪**:
  目标类型白名单、数量区间、奖励池(金钱 100~3000、道具限池内且数量封顶,
  大师球一类不会出现在委托奖励里);LLM 不可用或输出非法时**逐条回退本地生成器**。
- 完成即刻发放金钱与道具,并在聊天里显示"委托完成"提示。

### 🐾 培养
- 经验/升级按图鉴成长曲线;升级学招(招式满 4 个时进入「待学」队列,`/学招` 决定替换)。
- 进化覆盖:等级 / 亲密度 / 携带道具 / 学会指定招式 / 能力值分支 / 性别 / 昼夜 / 使用道具 / 通信交换。
- 捕获率、精灵球加成、异常状态加成、摇晃次数与真实公式一致。
- 性格 / 个体值 / 努力值 / 特性 / 太晶属性 / 性别 / 亲密度。
- 图鉴双记录(见到 / 捕获),`/图鉴` 可反查野外分布地点与等级区间。

### 🎮 战斗画面(仿 GBA《火红/叶绿》)
开启 `battle_image` 后,每次开战/出招/战斗结束都会附一张图片(用 `battle_image_scale` 调大小):
- **图形走像素、文字走清晰**:所有方块/血条/场地在 240×160 逻辑画布上用整数坐标绘制,
  最后 `NEAREST` 放大(默认 3 倍 → 720×480),文字在放大层绘制以保证中文可读。
- **我方是背面图**(和正作一致,看不到自己的宝可梦正脸);敌方用正面图。
- 还原正作控件:象牙色信息框 + 深绿双层描边 + 右下投影;血条一行是
  **精灵球图标 + 暗红「HP」标签 + 带刻度格纹的血条**;等级写作 `No.20`;
  我方额外有 HP 数值(`345/353`)与黄底「EXP」标签 + 青色经验条。
- 底部对话框:暗红外框 + 高光内线 + 青绿底 + 白字描边,左上角是队伍球(倒下画叉 + 打叉)。
- 场地:天气配色 + 地平线 + 大椭圆竞技场 + 两个椭圆站台;天气还会加粒子
  (下雨斜雨线、沙暴扬尘、下雪落雪、晴天转暖)。
- 右上角依次挂地名 / 天气 / 场地小标签。
- 渲染失败(缺字体/缺图)自动**回退为纯文本**,游戏不会因此中断。

### 🌍 每天凌晨 4 点刷新世界
- **世界事件**(全群共享):火箭队占据某地并封锁道路、宝可梦大量出现、稀有宝可梦现身、
  天气异常、商店清仓、庆典、道路封锁、旅人传闻。
- **个人事件**(每人独立):捡到道具/零花钱、遭遇野生宝可梦、训练家挑战、与宝可梦增进感情、私人线索。
- 由 LLM 按**严格 JSON** 生成:事件种类、地点、数值修正全部限定在枚举与区间内,
  越界的数值会被裁剪(例如 `encounter_mult: 999 → 3.0`)。
- LLM 不可用/超时/输出非法 → 自动回退本地确定性事件生成器,**游戏永不空转**。
- 机器人离线也不会漏:任意指令都会触发「懒刷新」补齐当天事件。

### 🧩 强规则(为什么不会被 LLM 玩坏)
| 层 | 职责 |
|---|---|
| `pw/dex.py` `pw/engine.py` `pw/growth.py` | 全部数值判定(不可被自然语言覆盖) |
| `pw/world.py` `pw/worldstate.py` `pw/daily.py` | 地图通行、事件施加与裁剪、日界 |
| `pw/narrate.py` + `prompts.py` | 只把**既成事实**润色成叙事,提示词明确禁止改动数值 |
| `main.py` | 指令 = 唯一的状态入口 |

## 安装

1. 把本目录放进 AstrBot 的 `data/plugins/astrbot_plugin_pokemon_world/`。
2. 无需 pip 安装任何依赖(数据已内置,运行时不联网)。
3. 在 WebUI 插件配置里填 `provider_id`(用于每日事件与叙事润色;留空则关闭 LLM 功能)。

### 🔒 对战中其他行动会被锁定
### 交换与携带

**玩家间交换**(同群、双方各自选一只,交换后**双方都触发通信进化**):

```
/交换 @小霞 2          # 小智:把队伍第 2 只摆上柜台(需在宝可梦中心)
/交换                  # 小霞:看到"小智想用 XX 换你的宝可梦"
/交换 接受 3           # 小霞:用第 3 只成交(需在宝可梦中心)
/交换 拒绝             # 或  /交换 取消 @小霞
```

- 报价写在**本群的世界状态**里(跨群不可见),`5` 分钟不回应自动失效
- 携带道具随宝可梦一起过去;需要的通信进化会**消耗**那件道具
  (例:大岩蛇带金属膜 ↔ 交换 → 大钢蛇)
- 对方那只若已不在 TA 的队伍/电脑里,请求作废并明确提示
- 收到的宝可梦若把队伍塞到 6 只,自动进电脑

**携带道具**:`/持有 <道具> [序号]` 装备、`/持有 取下 [序号]` 拿回背包、`/持有` 查看。
只有"携带后真有作用"的道具能装(剩饭/讲究头带/进化奇石/金属膜…),
消耗品会被拒绝。携带升级进化(锋锐之爪/浑圆之石…)也由此解锁。

**单人自连**:`/交换 <序号>` 只做"与远方训练家连接交换",宝可梦不会易主 ——
它只用来触发通信进化;需要携带道具的(16 种)要先 `/持有` 装上,
不带道具会被拒绝并提示要带什么。

一旦进入对战,**除"打这一场"之外的行动全部禁用**:`/探索`、`/前往`、`/治疗`、
`/商店 买/卖`、`/使用`、`/学招`、`/进化`、`/交换`、`/主线 挑战`、`/神兽 挑战`、
`/大赛 挑战`、`/道馆 挑战`、`/队伍 存入/取出/放生`、`/任务 放弃` 都会被拒绝,
并给出「出招 / 投球 / 换人 / 用药 / 逃跑」的指引。
打完(击败对手、被打败、逃跑、收服)或 `/对战 forfeit` 认输后自动恢复。
对战期间仍然允许**纯查看**:`/状态`、`/队伍`、`/宝可梦`、`/招式`、`/背包`、
`/电脑`、`/图鉴`、`/地图`、`/今日`、`/任务` —— 其中 `/招式 <序号>` 可以随时
查看招式的威力与**实际效果**,而且**不消耗回合**。

> 另外加了**僵局兜底**:双方连续 25 回合都没打出伤害时(数据里少数低级宝可梦
> 只有变化招的情况)判定「不了了之」结束战斗,不判胜负、不扣钱、不发奖励 ——
> 保证任何对局都能结束,不会把玩家卡在对战里。

## 存档

默认使用 **SQLite**(``data/pokemon_world/pokemon_world.db``,单文件):

- 表结构:`trainers(scope, uid, data, updated_day, updated_at)` /
  `worlds(scope, data, updated_at)`,存档本体仍是 JSON 文本存在 `data` 列;
- WAL 模式 + `busy_timeout`,写入用事务保证原子性(不再需要"临时文件 + rename");
- 配置 `storage` 设为 `json` 可退回旧版"每人一个 JSON 文件"的存储方式;
- **首次启动会自动导入**磁盘上的旧 JSON 存档,并把旧文件改名为
  `*.imported` 保留(不删除数据);导入是幂等的。

## 质量保障

- **158 个测试全绿**(含指令层端到端、引擎机制回归、界面越界回归、任务系统、数据完整性)
- **全量复核**:7 个专项审计按"战斗内核 / 委托事件 / 存档地图 / 指令层 / 对战界面 /
  成长主线 / 数据完整性"分头复核,发现的问题**必须先复现再报告**,修复后逐条补回归测试
- 已知的**有意简化**(文档中明确声明,不做静默降级):
  · 未实现:双打、极巨化、少数伪天气(奇妙空间/魔法空间);
  · 已实现:一击必杀(命中率 30%,对手等级更高则失败)、反击/镜面反射/金属爆破
    (按本回合受到的伤害计算,未区分物理/特殊)、报恩/撒气(按亲密度)、震级(真实震级表);
  · 仍不产生效果但会**明确提示玩家**、不会静默 0 伤害:`投掷`/`围攻`
    (依赖持有物投掷威力与队伍攻击力,暂未模拟);
  · 精灵图缺 1 张:数据源 PokeAPI 没有「超级基格尔德」的官方像素图(所有候选 URL
    均 404),渲染时按基础形态(基格尔德)显示,前后一致,并有回归测试锁住"缺图清单"。

### 第三方资源
- 字体:`pw/static/fonts/` 内置 **OPPO Sans Regular** 与 **Symbola**(用于图片渲染),
  分别遵循其原始发布许可;不使用可删除,渲染会自动回退为纯文本。
- **字体回退链**(逻辑与 `astrbot_plugin_life_sim` 的 `im_render/style.py` 一致):
  1. 主字体候选 = 内置字体 > 环境变量 `POKEMON_WORLD_FONT`(也认 `LIFE_SIM_FONT`)>
     插件根目录 `fonts/` > pillowmd 内置雅黑 > 系统常见 CJK 字体(含 WSL 的
     `/mnt/c/Windows/Fonts`);每个候选都会用 `ImageFont.truetype` **试打开**,
     损坏的字体自动跳过。
  2. 主字体整个加载失败 → 退回 Pillow 默认位图字体(不崩、不中断游戏)。
  3. **逐字符回退**:主字体缺字形时改用符号/emoji 字体(系统彩色 emoji 字体 >
     扫描系统字体目录 > 内置 Symbola),所以昵称/文本里的 emoji 也能画出来;
     位图字体(NotoColorEmoji)按内置尺寸加载后等比缩放贴回。
  4. 只有**所有字体都没有**的字符才会被丢弃(绝不画豆腐块);若字体覆盖信息读不到
     (没装 fontTools)则保守照常绘制,不误删文字。

> **已知缺口**:上游 `locations.json` 完全没有**帕底亚**的野外数据,因此《朱/紫》地区
> 无法生成地图与野外遭遇;但《朱/紫》的御三家与宝可梦(Gen9 全量)都能正常获得与对战。
